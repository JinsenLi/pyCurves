# Numerical Core

This package translates the Curves analysis stages into Python: base-frame
fitting, backbone geometry, helical-axis construction, local/global shape
parameters, and groove measurements. It supports legacy Curves 5.3-compatible
and standard Curves+/3DNA-style conventions.

See [`SCRIPT_REFERENCE.md`](SCRIPT_REFERENCE.md) for each module's role and the
order in which the stages run.
